Marca3 versões oficiais

O monograma "N" é a assinatura. A logo aparece em 3 fundos aprovados. Laranja da marca #FD5C02 para social e print; laranja digital #E85A1A na tela.

Gradiente · primária
Branca sobre laranja
Preta sobre off-white
FAZER
  • Usar a logo com respiro generoso ao redor
  • Manter o laranja como único acento
  • Preferir fundo navy ou gradiente laranja→navy
  • Usar o monograma isolado como ícone e marca d'água
NÃO FAZER
  • Colocar a logo sobre fundo branco puro
  • Trocar a fonte do wordmark
  • Adicionar segunda cor de destaque
  • Distorcer, inclinar ou aplicar sombra na logo
Sistema de Fundo3 camadas fixas

Toda página empilha as mesmas 3 camadas fixas sobre o navy: grade sutil de 80px, dois brilhos radiais (laranja no topo-esquerda, navy no rodapé-direita) e o monograma como marca d'água de 4% de opacidade.

Camada 1Grade 80px · branco .018
Camada 2Radiais laranja + navy
Camada 3Marca d'água · opacidade .04
Componentes8 blocos base

Os blocos reutilizáveis do sistema. Grids sempre com gap de 2px sobre fundo branco .05 (efeito de "linha divisória"), cantos 3–4px, barra laranja de 3px revelada no hover.

Tokens CSSCopiar & colar

Cole este bloco no topo de qualquer HTML novo e a identidade Nexo vem junto. Inclui o link das fontes.

nexo-tokens.css
/* Fontes — colar no <head> */
/* <link href="https://fonts.googleapis.com/css2?
   family=Bebas+Neue&family=Barlow+Condensed:
   ital,wght@0,700;0,900;1,700&
   family=Barlow:wght@400;700;900" rel="stylesheet"> */

:root{
  /* Cores base */
  --orange:#E85A1A;        /* acento UI */
  --orange-brand:#FD5C02;  /* marca */
  --navy:#08112A;
  --navy-mid:#0F1E40;
  --navy-light:#162D5E;
  --off:#F0EDE6;
  --gray:#C8C4BB;
  --muted:#7A7570;
  /* Superfícies (rgba sobre navy) */
  --card:rgba(255,255,255,.025);
  --card-hover:rgba(255,255,255,.05);
  --line:rgba(255,255,255,.08);
}
/* Fundo: navy + grade 80px + 2 radiais + monograma .04 */
body{font-family:'Barlow',sans-serif;font-weight:700;
